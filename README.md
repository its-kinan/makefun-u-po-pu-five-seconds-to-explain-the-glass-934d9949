A deterministic program that writes the one sentence a house cat would say in its own defence after knocking a glass off the table: the glass had been squatting in the cat's sunbeam like it paid rent, so the cat evicted it — no apology, no confession, just feline self-interest.

## Run it

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt` (137 characters, one sentence, deterministic — two runs produce byte-identical output).
